# StatorCoolingRing

StatorCoolingRing models an additively manufactured, emergent 12-path vascular liquid-cooling distributor manifold (`v3`) for an electric vehicle hairpin stator end-winding. Coolant enters through a fixed radial G3/8" inlet port at `X = -108 mm` (`Ø 13.0 mm`, `10 L/min` water at `20 °C`) and self-organizes into a 12-branch collector network through force-directed edge bundling, 3D-SDF obstacle avoidance around an asymmetric HV three-phase cable harness and sensor conduit, Murray's-law hydraulic diameter scaling, and frame-invariant 45-degree self-supporting DfAM teardrop cross-sections swept with `MIN_ROTATION` frames before discharging through twelve axial `Ø 4.0 mm` outlet nozzles on `Z = 0` at `R = 65.0 mm`.

Fourteen continuous growth-DNA parameters govern bundling strength and capture range, split release bias, Murray exponent, channel scale, free upper-to-lower symmetry/asymmetry watershed (`UpperLowerSplitBias`), open-tree vs. far-side loop closure (`FarSideLoopAttraction`), path stiffness, elevation profile, obstacle overpass bias, teardrop aspect ratio, and optional 1D hydraulic pre-balancing (`HydraulicBalanceGain` and `ResidualThroatTilt`). The solid engine combines the locally variable outer shell with an automatic collision-checked hourglass inter-tube rib matrix, topology-adaptive dome and flange support struts, `voxOverOffset` and `voxSmoothen` organic fillets, and a post-fillet sharp SW-24 hex wrench boss while preserving four M5 DIN-912 counterbored mounting domes, dual concentric O-ring sealing grooves, dowel pin bores, and a matching `*_context_environment.stl` reference mesh, with nine pre-CFD packaging constraints gating multi-objective `BoTorch` `qNEHVI` OpenFOAM optimization to minimize pressure drop and outlet flow imbalance simultaneously.
